Links in der Fußzeile stehen mittig zwischen Copyright und Versionsangabe – und zusätzlich
unter dem Anmeldefeld, damit Impressum und Datenschutz auch ohne Anmeldung erreichbar sind.

## Eigene Seite oder externer Link

rollen: admin

- **Eigene Seite:** bekommt eine Adresse unter `/seite/…` und einen Text aus dem Editor.
  Die Seite ist ohne Anmeldung lesbar. Der Editor kann Überschriften, Fett, Listen und Links;
  alles Weitere über **HTML-Quelltext**.
- **Externer Link:** führt auf eine andere Adresse und öffnet sich in einem neuen Tab.

Mit den Pfeilen links ändert sich die Reihenfolge, „Im Footer anzeigen" blendet einen Link
aus, ohne ihn zu löschen.

## Einbindung von Dienstleistern

rollen: admin

Manche Anbieter liefern die Datenschutzerklärung als Baustein zum Einbinden, meist ein
`<div>` und ein `<script>`. Der Code gehört in das Feld **Einbindung** einer eigenen Seite;
er wird unverändert unter dem Text eingefügt und ausgeführt. Nur Code aus vertrauenswürdiger
Quelle eintragen.
